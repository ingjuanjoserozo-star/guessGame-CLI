# 🎯 Guess Game CLI

A command-line number guessing game built in Python.

The application generates a random number (1–100).  
Users select a difficulty level that defines the maximum number of attempts.  
Execution time is measured using a custom `Timer` class, and the fastest completion times are ranked in a Top 3 leaderboard.

---

## 📚 Project Reference

This project is based on the Number Guessing Game challenge from  
[roadmap.sh](https://roadmap.sh/projects/number-guessing-game).

---

## ⚙️ Technical Overview

- Modular function-based structure  
- Object-oriented component (`Timer` class)  
- Dynamic difficulty configuration  
- High-resolution timing using `time.perf_counter()`  
- In-memory score ranking system  
- Controlled game loop with replay logic  

---

## 📦 Requirements

- Python 3.x
